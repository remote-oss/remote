# Contributing

Every pull request answers these six questions in its description:

1. Comments: only where the code cannot say it itself, never a conversation.
2. Names: four characters or more, saying what they hold.
3. Duplication: none; shared code is shared.
4. Dead code: none; everything is reached.
5. Tests: every branch, error path and boundary has one.
6. Coverage: the gate never falls.

CI enforces each of these; a request that fails a gate is not reviewed.
